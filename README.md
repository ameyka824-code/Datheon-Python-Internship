# Hangman Word Guessing Game

## About
A Python-based console Hangman game.

## Features
- Random word selection
- Letter-by-letter guessing
- Maximum 6 incorrect attempts
- ASCII Hangman drawing
- Victory and defeat messages

## Technology Used
- Python 3
- VS Code
- Random module

## How to Run
python hangman.py
